# Analysis of Real-World Attack Activity Against an Azure Windows Honeypot\
\
## A Practical SOC Project Using Azure, Microsoft Sentinel, KQL Analytics, GeoIP Enrichment, and Threat Visualization\
\
## Project Overview\
\
This project was designed to simulate a real-world Security Operations Center (SOC) monitoring workflow by deploying an intentionally exposed Windows virtual machine in Microsoft Azure and observing attack activity originating from the public internet.\
\
A Windows virtual machine was deployed within Azure and configured to collect Windows Security Event Logs. To attract attack traffic, the system was intentionally exposed to the internet through permissive network configurations. Security telemetry generated by the virtual machine was collected through Azure Log Analytics and analyzed using Microsoft Sentinel.\
\
Failed authentication attempts were investigated using Kusto Query Language (KQL), and attacker IP addresses were extracted from security logs. To provide additional context, a Python automation script was developed to enrich attacker IP addresses using the IPinfo API. The enriched data was then imported into Microsoft Sentinel as a Watchlist and visualized through a custom geospatial dashboard.\
\
This project demonstrates practical experience with cloud security monitoring, SIEM technologies, threat intelligence enrichment, security analytics, and SOC investigation workflows.\

## Key Project Components\
\
### 1. Azure Environment Setup\
\
- Deployed a Windows Virtual Machine in Microsoft Azure.\
- Assigned a public IP address for internet accessibility.\
- Modified NSG inbound rules to allow unrestricted inbound traffic.\
- Disabled Windows Defender Firewall to increase visibility of attack activity.\
- Generated realistic attack telemetry for monitoring and analysis.\
\
### 2. Log Collection and Monitoring\
\
- Created an Azure Log Analytics Workspace.\
- Connected Microsoft Sentinel to the workspace.\
- Installed and configured the Windows Security Events connector.\
- Collected Windows Security Event Logs from the virtual machine.\
- Monitored failed authentication events (Event ID 4625).\
\
### 3. KQL Analysis\
\
Investigated authentication activity using Kusto Query Language (KQL).\
\
Example query:\
\
```kusto\
SecurityEvent\
| where EventID == 4625\
| summarize Attempts=count() by IpAddress\
| order by Attempts desc\
```\
\
### 4. Threat Intelligence Enrichment\
\
- Exported attacker IP addresses from Microsoft Sentinel.\
- Created an IPinfo account and generated an API token.\
- Developed a Python automation script to enrich attacker IP addresses.\
- Retrieved:\
  - Network Provider (ASN)\
  - City\
  - Country\
  - Latitude\
  - Longitude\
- Generated an enriched dataset for visualization.\
\
### 5. Sentinel Watchlist Creation\
\
- Imported enriched attacker data into Microsoft Sentinel.\
- Created a custom Watchlist named **GeoIP**.\
- Used **IP Address** as the Search Key.\
- Verified successful ingestion using KQL.\
- The obtained enriched dataset was "manually" cleaned removing the username attribute due to sentinel constraint.\
\
### 6. Attack Visualization\
\
- Created a custom Microsoft Sentinel Workbook.\
- Imported map visualization configuration.\
- Correlated security events with enriched GeoIP data.\
- Generated an interactive world map displaying attack sources.\
\

## Key Findings\
\
- Identified **19 unique attacker IP addresses**.\
- Observed attack activity originating from multiple countries.\
- One IP address generated more than **284,000 failed login attempts**.\
- The high volume of authentication failures suggests automated attack activity, potentially involving a bot performing brute-force password guessing attempts against the exposed system.\
- Demonstrated how quickly publicly accessible systems attract malicious attention from automated scanning and attack infrastructure.\
